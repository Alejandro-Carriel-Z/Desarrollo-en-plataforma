Detalle del incidente INC-002

Acceso no autorizado a servidor

Severidad: Crítica

ID del incidente: INC-002

Fecha de registro: 01/09/2026 - 14:37

Estado: Contención en curso

Tipo: Acceso no autorizado

Reportado por: ana.martinez@empresa.com

Descripción del incidente:

Se detectó un intento de acceso no autorizado al servidor de producción (IP: 192.168.10.25) desde una dirección IP externa (203.0.113.45). El atacante intentó autenticarse mediante fuerza bruta durante aproximadamente 18 minutos. Se activaron las reglas de bloqueo automático y se isoló temporalmente el servidor afectado.

Actualización: Incidente en proceso de resolución.

Acciones tomadas:

  • Se bloqueó la dirección IP externa sospechosa.
  • Se revisaron los registros de acceso y se identificaron intentos fallidos.
  • Se notificó al equipo de seguridad para una investigación más profunda.
  • Se implementaron medidas adicionales de seguridad en el servidor afectado.
